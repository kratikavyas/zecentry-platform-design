# ZecEntry — Project Journal

## November 24, 2026

ZecEntry is an event-ticketing MVP exploring how Zcash payments can fit into a familiar event-booking experience.

### Product decisions

- Keep demo bookings separate from blockchain payment verification.
- Use signed, account-bound payment requests for the Zcash testnet flow.
- Verify transaction details server-side before issuing a ticket.
- Keep ticket check-in tied to booking references.
- Avoid enabling ticket transfers until a secure ownership-transfer flow exists.

### Current scope

The project includes event discovery, organizer event management, attendee ticket wallets, staff check-in, and a Zcash testnet payment-verification architecture.

Zcash support is currently testnet-only. Live end-to-end payment verification has not yet been demonstrated.

### What I'm exploring

Making privacy-oriented payment infrastructure approachable through everyday products, starting with event ticketing.
